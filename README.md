# hockey-flex

체격과 샷 특성으로 아이스하키 스틱 플렉스를 계산합니다. 의존성 없는 단일 HTML 파일이고, 한국어/영어와 라이트/다크를 지원합니다.

Calculates ice hockey stick flex from body size and shot characteristics. Single HTML file, no dependencies, Korean/English and light/dark.

```
F = 1.2243 × M^0.7 × H² × k_load × k_rel
```

`M` 몸무게(kg) · `H` 키(m) · `k_load` 로딩 계수 · `k_rel` 릴리스 계수

---

## 왜 "몸무게 ÷ 2"를 쓰지 않는가

업계 표준인 절반 규칙은 두 가지를 틀립니다.

**키를 무시합니다.** 스틱을 휘게 만드는 것은 힘이 아니라 모멘트이고, 모멘트는 팔 길이에 비례합니다. 같은 70kg이라도 165cm와 185cm는 스틱에 전혀 다른 하중을 겁니다.

**성인 상단에서 발산합니다.** 절반 규칙은 90kg에 99, 100kg에 110을 줍니다. 그런데 현실의 두 선수는 대개 같은 스틱을 씁니다. 초과 체중의 상당 부분이 지방이라 힘에 기여하지 않기 때문입니다.

| 체격 | 몸무게÷2 | 이 공식 (중립) |
|---|---:|---:|
| 135cm 30kg | 33 | **24** |
| 150cm 45kg | 50 | **40** |
| 165cm 60kg | 66 | **59** |
| 175cm 75kg | 83 | **77** |
| 185cm 90kg | 99 | **98** |
| 180cm 100kg | 110 | **100** |

하단이 특히 중요합니다. 절반 규칙은 30kg 아이에게 33 플렉스를 지시하지만, 유소년 규격의 실제 하한은 20입니다. 유연한 스틱이 어린 선수와 여성 선수의 퍽 속도를 높인다는 것은 1976년부터 반복 확인된 결과인데, 절반 규칙은 정확히 그 반대 방향을 가리킵니다.

## 유도

### 1. 왜 키가 제곱으로 들어가는가

블레이드에서 아래손까지 거리를 `a`, 양손 간격을 `d`, 손이 가하는 힘을 `P`라 하면 오버행 빔의 처짐은

```
δ ∝ P · d · a · (d + a) / EI
```

여기서 각 항이 체격에 어떻게 붙는지 봅니다.

- `P` — 근력은 근단면적을 따릅니다. 신체를 균일한 기둥으로 보면 질량 ∝ 단면적 × 키이므로 **`P ∝ M / H`**
- `d`, `a` — 둘 다 팔 길이와 스탠스에서 나오므로 **각각 `∝ H`**

대입하면 키가 힘에서 한 번 나누어지고 지렛대에서 세 번 곱해집니다.

```
δ ∝ (M/H) · H · H · H / EI  =  M · H² / EI
```

**제곱 항이 붙어야 할 곳은 스틱 길이가 아니라 키입니다.** 스틱을 잘라도 표기 플렉스가 변하지 않는 것과 같은 이유입니다 — 플렉스는 고정 스팬에서 측정되고 지지점 바깥은 애초에 휘지 않습니다. 자른 스틱이 뻣뻣하게 *느껴지는* 것은 손 간격이 좁아져 `d`가 줄기 때문이지 스틱이 변해서가 아닙니다.

### 2. 왜 질량 지수가 0.7인가

`P ∝ M/H`는 체중 전체가 힘에 기여한다고 가정합니다. 성인에게는 성립하지 않습니다. 질량 항에 제지방 알로메트리 지수를 적용해 `M^0.7`로 씁니다. 90kg와 100kg가 98과 100으로 수렴하는 것이 이 지수의 효과이고, 이 때문에 가벼운 체격에 대한 별도 보정 경고가 필요 없습니다.

### 3. 보정 계수

두 개의 서로 다른 물리적 제약이 각각 축을 이룹니다.

**`k_load` — 진폭 제약** `0.85 / 1.00 / 1.08`

저장 에너지는 `E = P² / 2k`입니다. 힘이 모자라 스틱을 충분히 못 휘게 하면 무를수록 무조건 유리합니다. 11세 선수와 여성 선수 연구에서 유연한 스틱이 더 빠른 퍽을 낸 것이 전부 이 구간입니다.

**`k_rel` — 타이밍 제약** `0.90 / 1.00 / 1.10`

휘어진 스틱이 릴리스 전에 되돌아와야 에너지가 퍽에 실립니다. 리코일 1/4주기는 `t = (π/2)√(m/k)`이고, 플레이 중 실효 강성 770–1000 N/m와 블레이드측 실효질량 0.25–0.45kg를 넣으면 **26–38 ms**가 나옵니다. 실측된 블레이드-퍽 접촉 시간이 32–39 ms이므로, 리코일 주기가 접촉 시간창 한복판에 앉아 있습니다.

`k ∝ 1/t²`이라 릴리스가 20% 짧아지면 필요 강성이 56% 올라갑니다. 다만 진폭 제약이 동시에 걸려 최적점이 두 제약의 교차점에 앉으므로, 순수 타이밍 스케일링을 그대로 쓰면 과대예측입니다. 실측으로 검증된 85/100/110 스팬에 맞춰 ±10%만 적용합니다.

### 4. 보정

175cm · 75kg · 중립 = **77 flex**. 기존 해외 표준 가이드와 같은 값이라 연속성이 유지됩니다.

## 이 계산기가 할 수 없는 것

이 분야 최대 데이터셋은 48명의 선수가 85/100/110 플렉스로 1,000회 이상 슛한 기록입니다. 여기서 선수를 분류하는 데 주성분 12–14개가 필요했고, **그 변수 목록에 키도 몸무게도 없습니다.** 판별 변수는 전부 변형-시간 곡선, 접촉 시간, 임펄스, 릴리스 시점 변형입니다.

같은 100 플렉스로 시험한 두 선수가 정반대 방향으로 매칭된 사례가 있습니다. 한 명은 스틱을 거의 못 휘어서 더 무른 85로, 다른 한 명은 너무 크게 휘어 리코일이 못 끝나서 더 뻣뻣한 110으로 갔습니다. 체격이 아니라 로딩 방식이 갈랐습니다.

**따라서 이 공식이 주는 숫자는 시험을 시작할 지점이지 정답이 아닙니다.**

### 실사격 검증

옆에서 슬로우로 찍어 릴리스 프레임을 보십시오.

| 릴리스 순간 스틱 상태 | 의미 | 조정 |
|---|---|---|
| 아직 뒤로 휘어 있음 | 리코일 미완료, 에너지가 퍽에 안 실림 | 더 뻣뻣하게 |
| 거의 안 휘어 있음 | 저장할 에너지 자체가 없음 | 더 무르게 |
| 막 펴져 0에 가까움 | 맞음 | — |

실제 피팅 데이터에서 한 선수는 100 플렉스에서 릴리스 변형이 −7.2cm였는데 110으로 올리자 +0.5cm로 0에 붙고 퍽 속도가 120 → 123 km/h로 올랐습니다. 접촉 시간과 임펄스는 오히려 나빠졌는데도요. **릴리스 시점 변형 하나가 나머지 지표를 전부 이깁니다.**

## 사용

`index.html`을 브라우저로 열면 끝입니다. 빌드도 서버도 필요 없습니다.

설정은 URL 쿼리로 공유됩니다.

```
?w=75&h=175&a=1&b=1&f=70
```

`w` 몸무게(kg) · `h` 키(cm) · `a` 로딩 축 0–2 · `b` 릴리스 축 0–2 · `f` 보유 스틱 플렉스(선택)
